# 《人人都能开发软件》

**用 AI 从想法走到上线——不会写代码，也能做出自己的软件**

作者：Tony Wu ｜ 联系：tonywoo@outlook.com

这是一本写给"有想法、没代码能力"的人的 vibe coding 实战书：从验证想法开始，
经过选工具、写提示词、做规划、搭 MVP、做界面、接 AI、测质量、上版本管理、
部署上线、做安全、接支付变现，一直到发布和增长——全链路手把手。

贯穿全书的案例是 **林小满**：一位不懂代码的烘焙店主，用 AI 从零做出线上订货系统，
收到第一笔在线订单。你会跟着她走完从 0 到 1 的全程。

## 技术栈（全书单栈）

- **Next.js + React + TypeScript + Tailwind CSS**，部署到 Vercel
- 示例项目在 `sample/` 目录，是真实可运行的完整项目（林小满的烘焙订货系统）
