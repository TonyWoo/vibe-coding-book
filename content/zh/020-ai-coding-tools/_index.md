**贯穿案例 · 林小满**

想法验证通过了：35 个邻居投票说愿意用网站下单。林小满干劲十足，打开电脑准备"让 AI 写网站"——然后傻眼了：Cursor、Claude Code、Lovable、Bolt、Replit、Codex……名字一个比一个酷，到底用哪个？

她先随手点开一个叫 Lovable 的网站，用中文打了一句话："我是社区烘焙店主，我要一个订货网站，用户能选面包、选明天早上 8 点取货。"十分钟后，一个真能点的网站出现在她面前。她激动得立刻给女儿打视频："你看，妈妈'做'了个网站！"

但第二天她就发现：想把"取货时间"从下拉框改成按钮，翻来覆去跟 AI 说了五遍，越改越乱。她这才明白：**选工具不是选"最厉害的"，是选"最适合你现在这一步的"**。这一章，就讲怎么选。

## 2.1 AI 编程工具分两大家族

市面上的 AI 编程工具，五花八门，但只分两大家族：

**第一家族：浏览器里点一点**（Lovable、Bolt、Replit）。你不用装任何东西，打开网页，用说话的方式描述需求，它直接给你一个能跑、能发链接的网站。一句话：**帮你把饭做好端上来**。

**第二家族：装在你电脑上的结对程序员**（Cursor、Claude Code、Codex）。它住在你的电脑里，能看到你的全部文件，帮你写代码、改代码、跑命令，你随时可以检查它干了什么。一句话：**站在你旁边陪你一起做饭**。

记住这个区别，后面所有的选择都从这来：前者快，后者稳；前者省心，后者自由。

## 2.2 懒人神器：浏览器里点一点

这类工具的玩法都差不多：注册账号 → 用一句话描述你要什么 → 等它生成 → 点开预览 → 一键发个链接给别人看。

优点很实在：零安装，手机浏览器都能用；从"有个想法"到"有个能点的链接"，最快的一批 10 分钟搞定。对林小满这种零基础的人，这是人生中第一次"做出软件"的体验——这种正反馈，千金难买。

缺点也要提前知道：代码放在人家平台上，拿回来不方便；想改细节只能靠"接着跟它说"，说多了有时候越改越乱；需求一复杂（比如要记订单、要分用户），它就开始力不从心。

所以它的定位是：**验证想法的神器，长期维护的起点**——注意，是起点，不是终点。

## 2.3 结对编程：住在你电脑里的 AI 程序员

**Cursor** 长得像一个写代码的软件（VS Code），AI 直接住在里面：选中一段代码就能问它，写一半它帮你补全，还能开"Agent 模式"让它一次改好几个文件。

**Claude Code** 住在终端（那个黑框框）里。你跟它说话，它能读你整个项目的文件，改完还能自己跑起来验证。

**Codex** 思路类似，各有各的脾气。

优点：代码实实在在在你自己电脑上，版本、备份、部署全由你说了算；项目越复杂、维护时间越长，越离不开这一类。

缺点：要装软件，要大概懂"文件""文件夹"是什么，第一次启动比浏览器型多花半小时。对纯小白来说，这半小时是道小门槛——但跨过去，海阔天空。

## 2.4 三道选择题，选出你的搭档

别纠结品牌，回答三道题，答案自己出来：

**第一题：你现在在哪一步？**
只有想法、想先验证 → 浏览器型。已经验证过、决定认真做 → 结对型。

**第二题：你愿意装个软件、学一点点基础吗？**
不愿意，先跑起来再说 → 浏览器型。愿意 → 结对型，走得更远。

**第三题：你的东西有多复杂？**
单页面、展示为主 → 浏览器型够了。多页面、要记数据、要分用户 → 结对型。

林小满的答案：先用浏览器型 20 分钟做出第一版，发到顾客群验证；投票结果很好，决定认真做之后，再换 Cursor 把代码"接管"到自己电脑上。**两步走，不丢人**——全世界最聪明的程序员，也是从"先跑起来"开始的。

## 2.5 跟着做：让 AI 生出你的第一个页面

以浏览器型为例，跟着走一遍（结对型的上手放在第 7 章）：

1. 打开工具网站，注册账号（一般用邮箱就行）。
2. 在输入框里粘贴你的"需求描述"。模板来了，照抄：
   > 我是___（你是谁），我要做一个___（做什么），用户能___（列 2-3 个最核心的操作），风格要___（比如温暖简洁），不要___（比如不要太花哨、不要英文界面）。
3. 等它生成，点开预览。
4. 验收三看：**能不能点？像不像我要的？链接能不能发给别人？**三看都过，才算数。

林小满的第一次描述就是按这个模板写的，一次成型。她说："原来把话说清楚，AI 真的听得懂。"

## 2.6 别交智商税

- **坑一：三个工具来回倒。** 今天 Lovable 明天 Bolt，后天又听说 Cursor 好。选一个，用完一个阶段再换。工具是路，换来换去到不了地方。
- **坑二：太早为"高级功能"付费。** 先把免费额度榨干，真的不够用了再掏钱。你的项目还小，配不上 Pro。
- **坑三：把钥匙交出去。** 账号密码、支付密钥、私人信息，别往对话框里贴。第 12 章会细讲安全，这里先记住一句话：**AI 是搭档，不是保险箱**。
- **坑四：信工具鄙视链。** "不用 Claude Code 的都是外行"——别理。没有最好的工具，只有最适合你现在这一步的。

## 2.7 在国内：Claude Code + DeepSeek 这条路

如果你在国内，会发现一个现实问题：Claude Code 连的是 Anthropic 的官方服务，国内直连不稳。但别急着放弃——**壳可以换芯**：Claude Code 这个"壳"不变，把背后的"脑"换成 DeepSeek，又便宜又稳。

四步走：

**第零步：先装 Node.js。** 后面那两个软件都是用 npm 装的，而 npm 是跟着 Node.js 一起来的——先有 Node，才有 npm 这个"应用商店"。去 nodejs.org 下载 **LTS 版本**（长期支持版，最稳），Windows 和 Mac 都是图形界面，一路下一步。装完验证一下：打开终端（Windows 按 Win+R 输入 cmd 回车，Mac 打开"终端"这个应用），输入 `node -v`，能显示出版本号（比如 v22.x.x）就是装好了。

**第一步：准备钥匙。** 去 DeepSeek 开放平台注册，创建一个 API Key（`sk-` 开头，只显示一次，复制保存好）。注意 DeepSeek 是**预付费**，先充十块钱，余额为 0 会报错。

**第二步：装两个软件。** 先装 Claude Code：`npm install -g @anthropic-ai/claude-code`；再装一个"切换器" CC Switch（有图形界面版，下载安装、一路下一步就行），它负责把 Claude Code 的请求转接到 DeepSeek。

**第三步：配好，开工。** 在 CC Switch 里选 DeepSeek、粘贴 Key。**关键一步：模型映射改成 V4**（默认的 V3 已经不可用）。然后进项目目录，输入 `claude`，回车，开始干活。

听到"终端""npm"就头大？别怕，第 7 章会手把手带你走第一遍。先记住有这条路就行：**人在国内，一样能用上顶级的 AI 编程搭档，只是换了个更便宜的"脑"。**

还有一条更野的路：DeepSeek 官方开源了一个叫 dsh 的 harness，`npm i -g @deepseek-ai/dsh` 装上，`dsh web` 在浏览器里就能用，模型随便换。等你玩熟了 Claude Code 再去尝鲜不迟。

## 本章要点

1. 两大家族：浏览器生成型（快、省心）vs 本地结对型（稳、自由）。
2. 先验证用浏览器型，认真做换结对型——林小满的两步走是标准答案。
3. 代码在谁手里，决定了你能走多远。
4. 工具选"适合现在"，不选"最贵最火"。
5. 在国内用 Claude Code：壳不变、芯换 DeepSeek，CC Switch 转接，模型映射记得改 V4。

## 动手 Kata

1. 用浏览器型工具，按 2.5 节的模板生成你的第一个页面。
2. 把链接发给 3 个朋友，收集原话反馈。
3. 记下来：哪里满意、哪里想改但改不动——"改不动"的清单，就是你将来换结对型工具的理由。

## 翻车现场

阿凯是林小满顾客群里的年轻人，听说 Claude Code 是"地表最强"，第一天就装上了。结果他连"cd 到项目目录"都不会，对着黑框框发了三句"hello"，AI 回了他一堆看不懂的英文。折腾两天，他卸载了，结论："AI 编程是骗局。"

他错的不是工具，是顺序。零基础第一步该用浏览器型，先尝到"做出来"的甜头，再学走路。**工具没有错，错的是起跑线。**
